Dogecoin Milk Sad Keys

Dogecoin wallets using BIP-44 derivation path m/44'/3'/0'/0/0 from weak Libbitcoin seeds are vulnerable to the Milk Sad attack.

Despite Dogecoin's different parameters, the PRNG weakness affects all cryptocurrencies using mnemonics from bx seed.
