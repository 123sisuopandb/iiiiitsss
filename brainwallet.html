What is a Brain Wallet?

A brain wallet is a cryptocurrency wallet where the private key is derived from a passphrase that you memorize. Instead of storing a random 256-bit number, you use a memorable phrase that gets hashed (typically with SHA-256) to create the private key. The idea is that you can "store" your cryptocurrency in your brain.

Why Are Brain Wallets Dangerous?

Brain wallets are extremely vulnerable to brute-force attacks. Hackers run automated scripts that continuously hash billions of common phrases, dictionary words, famous quotes, song lyrics, and password combinations. When they find a match with a funded address, they instantly steal the funds. Any passphrase you can think of has likely already been tried.

What This Database Shows

This database contains 18,890 weak passphrases that have been used to create brain wallets. Many of these addresses have received and lost funds to automated sweeper bots. This serves as educational proof that brain wallets should never be used for storing real cryptocurrency.

Safe Alternatives

Instead of brain wallets, use properly generated random private keys or BIP-39 mnemonic phrases (12/24 words from a standardized wordlist). Hardware wallets like Ledger or Trezor provide the best security for significant holdings.
